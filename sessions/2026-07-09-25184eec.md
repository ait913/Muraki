## 課題点

- ローカルの node/esbuild 環境が会期途中から不調
  - **何が課題か**: `vite build` が config bundle 段で ENOEXEC/ハング、`tsx` の API 起動もハング。session 序盤（初回ビルド16:10）は動いていた。ローカル検証（build/dev/API/実値取得）が全滅した。
  - **いつ起こるか**: シミュレータ + tsx watcher で高負荷になった後あたりから恒常化。`timeout` コマンドが macOS に無く空振りした無駄手もあった。
  - **次どうするか**: 本番は Coolify(Linux) が通るので実害は無いが、ローカルで触る前に `pnpm -C apps/web build` が通るか確認。ダメなら node/pnpm 再インストールか再起動。macOS では `timeout` でなく `gtimeout` or ハーネス側 timeout を使う。
- iOS の誤ビルド・インストール
  - **何が課題か**: `find … Atender.app | head -1` が**最古の DerivedData**を掴み、旧オレンジ版を install→「直ってない」と誤認。
  - **いつ起こるか**: `Atender.xcodeproj` と untracked の `Atender 2.xcodeproj` が併存し DerivedData が複数あるとき。
  - **次どうするか**: `xcodebuild -showBuildSettings` の `TARGET_BUILD_DIR` から正確な .app パスを取る。head -1 で決め打ちしない。
- ブランド表記の見落とし
  - **何が課題か**: ヘッダー変更が wide で反映されず。TopBar(mobile) だけ直して SideNav/AuthLayout を見落とした。
  - **いつ起こるか**: 同じ文言が複数レイアウトコンポーネントに分散しているとき。
  - **次どうするか**: 表記変更は最初に `grep -rn ">Atender<\|>atender<"` 等で全出現を洗ってから着手。
- バグの決め打ち
  - **何が課題か**: 出席率バグを「小数(12.5)」と推測先行で断定しかけ、AskUserQuestion まで作ったがユーザーの実値(264/306=整数)で外れていた。
  - **いつ起こるか**: 実データ再現ができず、コード解析だけで症状を仮定したとき。
  - **次どうするか**: 環境が動くなら実値を取ってから症状を確定。取れないなら「こう出ているはず」を必ず確認質問で裏取りしてから修正方針に進む。
