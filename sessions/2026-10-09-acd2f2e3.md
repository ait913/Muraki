## 課題点

1. **ストア素材に実ユーザーの投稿を使った** — 何が: live (dev1 login-as) で撮った S2 に Touri のテスト投稿のサムネが写り、未 push 履歴に入った。履歴の書き換え (`filter-branch`) は permission で止まり、結局 private 履歴に残す判断になった。いつ: サムネ付きの画面が欲しくて安易に live を選んだとき。次: 素材は demo + 生成画像のみ、`mocks/store/shots/` は git 管理外 (bloom CLAUDE.md に規約化済み)
2. **コピーを 2 回 AI 臭いと却下された** — 何が: 否定の対句・読点の決めぜりふ・擬人法で書いた。いつ: 「キャッチー」を求められたとき。次: 文言は最初から Codex に独立案と「AI っぽさの型」の分解を取り、実アプリの UX ライティング (whoo / BeReal) を基準に書く
3. **Leader が Touri の手を借りようとして往復が増えた** — 何が: `filter-branch` を Touri にコマンドで実行させようとし、そもそもの「何のために / 何が問題か」の説明が後回しになった。次: 権限で止まったら、まず実害の評価と「やらない」選択肢を 1 行で出す
4. **シミュレータビルドの手順が壊れていた** — 何が: docs の `--no-codesign` で Keychain 書き込みが -34018、live shot が LaunchScreen で止まった。次: 修正済み (`knowledge/gotcha/flutter-sim-no-codesign-keychain-34018.md`)
5. **Reviewer agent が rate limit で途中終了** — 何が: Fable の上限で server テストの分類途中に止まった。次: 長い Reviewer は Sonnet で回す (後半はそうした)。引継ぎは作業ツリーの未コミット差分から再開できた
