## 課題点

- 並列レーンの simulator build がディスクを食い潰した
  - **何が課題か**: 3 レーン同時に flutter build ios --simulator (各数 GB) + DerivedData 34GB で ENOSPC、全ツールが停止、ユーザーは外出中で手を出せなかった。
  - **いつ起こるか**: 並列 developer/reviewer に simulator build を許すとき。
  - **次どうするか**: 召集時に「xcodebuild は pgrep で直列化、終わったら app/build 削除、空き 15GB 未満で停止」を必ず入れる。


- 「サーバー先行 = 旧版が見えなくなる」という誤解が裁定に入っていた
  - **何が課題か**: Touri は「先にサーバー更新すると旧版から見えなくなる」と認識して審査後反映を選んでいた。Leader は 10-1/10-2 の選択肢を出したが、旧版が締め出されるのは MIN_CLIENT_BUILD を上げた時だけ、という前提を明示していなかった。
  - **いつ起こるか**: リリース順序の裁定を仰ぐとき。
  - **次どうするか**: 選択肢の説明に「既存ユーザーに何が起きるか」を両案とも 1 行で書く。
- 説明の誤り 2 件を後から訂正した
  - **何が課題か**: 「ビットレートは指定せず iOS 推奨」「動画ファイルは共有して容量増えない」を設計 doc 確認前に断言し、のちに訂正。
  - **いつ起こるか**: Researcher/Architect の結論前に Touri へ見通しを答えるとき。
  - **次どうするか**: 見通しは「未確認」と付けて答える。
- Xcode Cloud の 502 は原因不明のまま復旧
  - **何が課題か**: 5 時間・5 ビルド失敗、規約・証明書・Xcode 版・バンドル ID 構成は全て問題なし、Apple status にも出ず。
  - **いつ起こるか**: Xcode Cloud export 段で `listTeams` 502。
