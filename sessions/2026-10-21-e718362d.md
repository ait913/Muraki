  - **次どうするか**: Reviewer ブリーフに「競合 (2 接続同時)、文字参照/大小文字/空白のバリエーション、フラグ両値 (allow_external True/False 等) を機械的に総当たり」を定型チェックとして入れる (role/reviewer.md に追記候補)
- **Codex の安全フィルタ** — 「try to bypass」で判定なし終了。言い回しを仕様適合検証に変えて回避 (tool-quirk に記録済)
- **Leader の裁定が往復した** (count_active の READY、チャンク不一致の ERROR 遷移) — Architect の doc 更新と Developer の実装が同時進行で、Leader の口頭裁定と doc が一時的にずれて Developer が doc に従い直す手戻りが出た。裁定は先に doc に書かせてから Developer に渡す順にする
