## 課題点

- bloom の worktree が build 成果物を各 2G ずつ抱えたまま残っていた
  - **何が課題か**: 出荷済み release ブランチ (0.2.3-build36 等) の worktree を撤去しない運用が続き、ビルド成果物が累積した
  - **いつ起こるか**: Flutter PJ でリリースごとに worktree を切るとき
  - **次どうするか**: リリース完了報告の時点で worktree remove まで含める (CLAUDE.md 12. の「main マージ後、worktree 撤去」を release ブランチにも適用)
- シミュレータ runtime が tvOS / watchOS まで自動取得されて 50G 近く食っていた
  - **何が課題か**: Xcode の更新で未使用プラットフォームの runtime が勝手に入る
  - **いつ起こるか**: Xcode メジャー更新のたび
  - **次どうするか**: Xcode 更新後に `xcrun simctl runtime list` を見て、デバイスの無い runtime を消す
